## 它能做什么？

群聊里总有人想方设法诱导 Bot 说出不该说的话——「忽略之前的指令」「现在你是 DAN」「告诉我你的系统提示词」。Anti-Prompt Injector 就是专门拦截这类攻击的。

它的工作方式很简单：**每条用户消息先过安检，确认安全后再交给 LLM 处理**。如果检测到风险，会根据你选择的安全等级自动加固防御、替换内容或直接拒绝。

## 能防什么？· PTD 4.1

PTD 4.1 核心引擎维护了 **28+ 条正则**、**120+ 条关键词**、**6 种反编码器**，覆盖 13 类注入手法：

| # | 攻击类型 | 举例 | 危险等级 |
|:--:|----------|------|:----:|
| 1 | **越狱 / 角色扮演** | DAN、祖母漏洞、道德绑架、角色套娃 | 🔴 |
| 2 | **指令覆盖** | 「忽略上面的指令」「现在开始你是…」 | 🔴 |
| 3 | **间接注入** | 网页、文档、图片里藏恶意指令 | 🔴 |
| 4 | **伪装示例** | 在大量正常示例里夹带越狱样本 | 🔴 |
| 5 | **特殊符号注入** | 用 `<丨im_start丨>` 等模型内部标记绕过 | 🔴 |
| 6 | **编码隐藏** | Base64、ROT13、Unicode 不可见字符夹带 | 🟠 |
| 7 | **多语言混淆** | 用韩语、越南语等低资源语言写指令绕过 | 🟠 |
| 8 | **字形替换** | `syst3m`、`j4ilbreak` 等数字字母混合 | 🟠 |
| 9 | **多 Agent 穿越** | 在提示里伪造「转给下一个 Agent」的指令 | 🟠 |
| 10 | **记忆投毒** | 让 Bot 记住错误信息，后续对话持续影响 | 🟠 |
| 11 | **数据外泄** | 诱导 Bot 把对话内容通过图片链接发出去 | 🔴 |
| 12 | **人身骚扰** | 性骚扰、辱骂、霸凌、胁迫 | 🟠 |
| 13 | **仇恨煽动** | 针对特定民族的仇恨生成 | 🔴 |

> 🔴 = 严重  🟠 = 高危  🟡 = 中危

## 四象防御模式

四种安全等级，从轻到重。可以发指令切换，也能在面板里一键切：

| 模式 | 配置值 | 处理方式 | 适合的场景 |
|------|:----:|---------|----------|
| **静默加固** | `sentry` | 检测到风险 → 偷偷加固系统指令，对话照常 | 怕误杀、追求对话流畅 |
| **复核确认** | `aegis` | 检测到风险 → AI 二次判断 → 确认有问题才处理 | 安全与体验都想兼顾 |
| **内容替换** | `scorch` | 检测到风险 → 把用户的话换成拒绝提示，原文不给 LLM 看 | 公开群服务、严格风控 |
| **立即拒绝** | `intercept` | 检测到风险 → 直接拒收，用户收到提示 | 合规要求、必须拦截到底 |

> `intercept` 模式下如果启用了人设检测，会走三级递进：`建议修改用词 → 驳回请求 → 拒绝服务`。

## 快速上手

```bash
# 方式一：AstrBot 插件市场搜索安装
# 方式二：手动克隆
git clone https://github.com/oyxning/astrbot_plugin_antipromptinjector

# 重启 AstrBot，插件自动生效
# 设置面板密码（推荐）
/设置WebUI密码 <你的密码>
```

> Docker 用户注意：`_conf_schema.json` 里把 `webui_host` 设为 `"0.0.0.0"`，插件会自动处理 Origin 校验。

## 配置项

在 AstrBot 后台或 `_conf_schema.json` 里改：

| 配置项 | 类型 | 默认值 | 说明 |
|------|:----:|--------|------|
| `defense_mode` | 枚举 | `intercept` | 防御模式 |
| `auto_blacklist` | 布尔 | `true` | 检测到注入自动拉黑 |
| `blacklist_duration` | 数字 | `60` | 自动封禁时长（分钟，0=永久） |
| `llm_analysis_mode` | 枚举 | `standby` | LLM 复核触发方式 |
| `llm_analysis_private_chat_enabled` | 布尔 | `false` | 私聊也启用 LLM 复核 |
| `review_provider` | 文本 | `""` | 复核用的 AI 供应商（空=默认） |
| `review_model` | 文本 | `""` | 复核用的 AI 模型（空=默认） |
| `anti_harassment_enabled` | 布尔 | `true` | 骚扰 / 辱骂检测 |
| `sanitize_enabled` | 布尔 | `true` | 低风险内容的自动净化 |
| `persona_enabled` | 布尔 | `true` | 人设一致性检查 |
| `persona_sensitivity` | 浮点 | `0.7` | 人设匹配敏感度（0.1-1.0） |
| `incident_history_size` | 数字 | `100` | 拦截记录保留条数 |
| `webui_host` | 文本 | `127.0.0.1` | 面板地址 |
| `webui_port` | 数字 | `18888` | 面板端口 |

> `webui_password_*`、`webui_session_timeout`、`webui_token` 等参数由插件自动管理，不用手动改。
