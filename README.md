# AntiPromptInjector

AstrBot 的提示词防护插件。检查本轮文本，按配置给主模型追加固定安全提醒、调用审查模型，或停止本轮请求。规则分表示命中证据的权重，不是攻击概率。检测豁免不是管理权限。

## 安装与升级

[查看各版本更新](CHANGELOG.md)。

4.1.0 以 AstrBot **v4.29.4** 为基线，不需要 ChatUI 工作台。在原插件目录更新，保留 `antipromptinjector` 标识。通过 Dashboard 的插件页面打开「设置中心」；不再启动独立 HTTP 服务，也不再使用旧面板密码或端口。

升级前请看[备份、旧名单认领和回滚](docs/upgrade.md)。不要卸载并删除原配置后再安装。新安装默认使用 `sentry`，**自动封禁关闭**。旧版纯 ID 白名单须由管理员绑定平台和实例后才能生效；旧封禁保留有效期。已丢失的旧进程内存日志无法恢复。

## 防护设置

| 模式 | 本轮动作 |
| --- | --- |
| `sentry` | 本地规则命中时追加固定提醒，对话继续；不调用复核，不自动封禁。 |
| `aegis` | 可疑文本必须复核。安全则放行，确认技术注入则加固。复核未完成不能算安全。 |
| `scorch` | 仅在能验证完整隔离时允许替换；不能证明时停止本轮，不清空几个字段就继续发送。 |
| `intercept` | 停止本轮主请求并给出简短提示；启用复核时，安全结论可纠正规则误报。 |

`standby` 在有证据或检查未完成时按模式复核，`active` 主动复核，`disabled` 禁用。私聊复核默认关闭。仅因 `active` 审查普通请求时，网络、超时、无效输出等故障默认记录后放行；已有可疑证据时阻断。严格策略会停止所有需要复核却未完成的请求。检查超预算单独记录。`sentry` 不调用模型，不受复核失败策略影响。

手动封禁优先于白名单和观察。临时观察只记录拟执行动作，不改写请求、不增加处罚；到期后继续按原设置工作。自动封禁只可能发生在已启用处罚、模型确认技术注入、输入可归责且实际阻断或替换的情况下。人设偏好和不当表达只作建议。

## 管理

设置中心与宿主原生表单共用同一份插件配置。设置中心可以管理名单、筛选和导出保留窗口内的诊断、试算单条样例。规则试算不调用模型；单独的模型试算可能计费。两者都不会写入名单或诊断。插件不读取或导出 Dashboard 登录令牌。

从 4.1.0 起，「模型复核」可下拉选择 AstrBot 已启用的对话提供商，再选择该提供商的模型；不指定则跟随会话。「防护设置 → 委婉拒绝」默认关闭。开启后，只有因注入风险实际阻断时，才按当前人格生成一句拒绝，可能产生一次额外模型调用。默认使用会话的对话模型，也可单独指定提供商和模型。生成请求只带人格设定，不带被拦截的消息、聊天历史或工具。生成不可用时仍然阻断，并发送固定提示；观察、静默加固、已有封禁及复核故障不会触发这次调用。

| 命令 | 用途 |
| --- | --- |
| `/反注入帮助`、`/查看管理员状态` | 所有人可查看帮助和自己的管理权限 |
| `/切换防护模式`、`/切换观察模式 [分钟]` | 循环切换模式；开始观察，`0` 提前结束 |
| `/LLM分析状态`、`/设置审查LLM [Provider ID] [模型]` | 查看状态、设置审查渠道 |
| `/开启LLM注入分析`、`/关闭LLM注入分析` | 切换至 `active` 或 `disabled` |
| `/开启防骚扰`、`/关闭防骚扰` | 开关不当表达建议 |
| `/拉黑 <ID> [分钟]`、`/解封 <ID>`、`/查看黑名单` | 管理当前会话封禁，`0` 表示永久 |
| `/添加防注入白名单ID <ID>`、`/移除防注入白名单ID <ID>`、`/查看防注入白名单` | 管理检测豁免 |
| `/反注入统计`、`/清除反注入记录 确认` | 统计或清除诊断，不修改名单和设置 |

除帮助和个人权限状态外，聊天管理命令均要求 **AstrBot 管理员**。仅有平台群管理身份、检测豁免或人设关系不授予该权限。

## 覆盖与来源

本插件不提供宿主工具权限，不承诺拦截已经开始执行的工具，不能对其他插件直接调用 Provider 的行为作保证。不对图片做 OCR，不按历史消息重复处罚当前用户。详见[字段与调用边界](docs/coverage.md)、[固定样例和结果](docs/baseline.md)。

沿用原插件和 AGPL-3.0 许可证。原作者 LumineStory，感谢 oyxning、lxfight、Hongming Chen 及其他上游贡献者。人设配置项的工作见 [yomihime 的 #18](https://github.com/oyxning/astrbot_plugin_antipromptinjector/pull/18)；[woshitiaoqu 的 #19](https://github.com/oyxning/astrbot_plugin_antipromptinjector/pull/19) 针对旧独立 WebUI，本版移除了该服务，未移植其来源校验补丁。设置中心的组织参考了 anka-afk 的表情包管理器。
